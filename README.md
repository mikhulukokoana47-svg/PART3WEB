## Project Overview
This repository contains the complete source code for the Medigrow ZA website. Medigrow ZA is a pioneering South African company established in 2017 that has evolved from a cannabis industry consultancy into a major industrial force in the medicinal cannabis sector. Under the leadership of CEO Edgar Adams, the company has embarked on an ambitious R1 billion investment to establish a state-of-the-art cannabis processing facility at the Coega Special Economic Zone in Gqeberha, Eastern Cape. 

This website serves as a central digital hub to inform the public, attract international investors, and facilitate the onboarding of local rural hemp farmers into the Medigrow ZA supply chain.

## Website Goals and Objectives
- **Provide Comprehensive Information:** Serve as the central hub for information regarding the R1 billion investment and the Coega SEZ facility.
- **Facilitate Farmer Onboarding:** Explain the process, requirements, and benefits of becoming a licensed hemp supplier.
- **Communicate Credibility:** Showcase adherence to SAHPRA and GMP standards to build trust with international export partners.
- **User Engagement:** Provide intuitive navigation and interactive forms for enquiries and direct communication.

## Key Features and Functionality
- **Responsive Design:** A mobile-first approach using CSS Flexbox and Grid, ensuring the site looks great on desktops, tablets, and mobile phones.
- **Interactive Elements:** A JavaScript-powered accordion on the services page and a dynamic search filter for products.
- **Form Validation:** Custom JavaScript validation on the Enquiry and Contact forms to ensure user input is correct (e.g., valid email formats, minimum character lengths) before submission.
- **SEO Optimized:** Implementation of meta descriptions, keywords, and heading hierarchies across all pages, along with `robots.txt` and `sitemap.xml` files.
- **Live Deployment:** The website is deployed and hosted for free via GitHub Pages.

## Timeline and Milestones
